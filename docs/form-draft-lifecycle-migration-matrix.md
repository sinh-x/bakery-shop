The baseline is the union of provider declarations added by the named commits, not merely files whose names contain `form`. This intentionally classifies list, filter, expansion, viewer, and other non-draft state as `EXCLUDE`, rather than silently dropping it. Consumers include every current `app/lib` reference found by exact provider-symbol search. Test-only references are named in the Tests column.

## Reading The Matrix

- **Owner / consumers** uses paths relative to `app/lib/`; the owner is listed first, followed by all production consumers. A dash means the baseline symbol currently has no production consumer.
- **Lifetime** is the live Riverpod lifetime in the application `ProviderScope`. `global` means one unkeyed instance; `family(key)` means one instance per equality-compatible family argument. Auto-disposal is called out explicitly where used.
- **Paths** always records `S` success, `E` error, and `C` cancel/back/swipe behavior. `n/a` means the state has no operation or dismissal lifecycle.
- **Tests** distinguishes targeted lifecycle coverage from general feature tests. `none` means no direct current symbol reference was found under `app/test`.
- **Disposition** is one of `MIGRATED` (production uses the contextual/session contract), `SUPERSEDED` (a baseline compatibility declaration replaced in production by a contextual companion), `INFRASTRUCTURE` (shared lifecycle primitive), or `EXCLUDE` (not retained form data). Every row has exactly one final disposition.
- Every row records context, initialization, success/error/cancel behavior, risk, evidence, and final disposition. No row remains planned or unclassified.
